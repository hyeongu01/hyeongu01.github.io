## 구현
```swift
import Foundation

func selectionSort(for array: [Int]) -> [Int] {
    var origin = array
    var res: [Int] = []
    
    while true {
        guard 
	        let min = origin.min(), 
	        let index = origin.firstIndex(of: min) 
		else {
            break
        }
        origin.remove(at: index)
        res.append(min)
    }
    return res
}
```

## AI를 활용해 개선하기
### 초기 AI 피드백
- AI 가 짚어준 코드의 문제점은 다음과 같다.
	- `Array.remove(at: )` 의 비효율성
	- origin, res 를 따로 사용하여 O(2N)의 공간복잡도
- 해결 방안
	- `Array.swapAt()` 매서드 활용

### 1차 개선한 코드
```swift
func selectionSort(for array: [Int]) -> [Int] {
    var res = array
    
    for i in 0..<array.count {
        guard
            let min = res[i...].min(),
            let index = res[i...].firstIndex(of: min)
        else {
            return []
        }
        res.swapAt(i, index)
    }
    
    return res
}
```

- AI의 답변
	- 최소 index 를 구하는 데 min을 구하고 (`O(N)`), index를 구하는(`O(N)`) 작업을 불필요하게 하게 되어 불필요한 연산을 함
- 해결 방안
	- 최소값의 인덱스를 구하는 것을 한 번에 하자!

### 2차 개선한 코드
```swift
func selectionSort(for array: [Int]) -> [Int] {
    var res = array
    let arraySize = array.count
    
    for i in 0..<arraySize {
        var min = res[i]
        var minIndex = i
        
        for j in (i+1)..<arraySize {
            if min > res[j] {
                min = res[j]
                minIndex = j
            }
        }
        res.swapAt(i, minIndex)
    }
    
    return res
}
```

- AI의 답변
	- 중복 순회 제거
		- 이전 버전의 `min()` + `firstIndex(of: )` -> 2번 순회
		- 지금은 1번의 루프에서 min 과 minIndex 를 동시에 탐색 -> 1번 순회
	- 제자리 정렬
		- 메모리 사용: `O(N)`
		- array 를 inout 으로 사용한다면 `O(1)` 도 가능!

## 후기
- AI 의 피드백
	- 처음 개념을 정리하고 구현 할 때에는 첫 번째 코드가 최선인 것 같았는데, AI가 꼼꼼하게 피드백 해 줘서 더 효율적으로 구현할 수 있었다.
- 테스트 코드 기반 설계
	- 구현하기 전에 원하는 동작을 검증하는 테스트 코드를 작성해 두어 코드를 개선할 때 마다 여전히 올바르게 동작하는지를 파악할 수 있었다.
