## 문제 소개
---
* 문제 주제: 비밀번호 찾기
* 문제 링크: [백준: 17219번](https://www.acmicpc.net/problem/17219)

```md
# 입력 형식
첫째 줄에 저장된 사이트 주소의 수 N, 비밀번호 찾으려는 사이트 주소 수 M
두 번쨰 줄부터 N개의 줄에 사이트 주소와 비밀번호가 공백으로 구분되어 주어진다.
N+2번째 줄부터 M개의 줄에 걸쳐 비밀번호 찾으려는 사이트 주소가 한 줄에 하나씩 주어진다.
- (1 <= N, M <= 100,000)
- (1 <= 사이트 주소 길이, 비밀번호 길이 <= 20)
- 사이트 주소는 알파벳 소문자, 대문자, 대시, 마침표로 이루어져 있다.
- 비밀번호는 알파벳 대문자로만 이루어져 있다.

# 출력 형식
M개의 비밀번호를 한 줄에 하나씩 출력
```

## 문제 분석 & 접근 방식 설정
---
- 사이트, 비밀번호를 쌍으로 저장할 방법
	- `map<string, string>`자료구조에 저장!
- 저장된 사이트를 검색할 방법
	- map은 자동 정렬되어 있다.

> map 자료구조에 사이트, 비밀번호 쌍을 정렬하면서 저장하고, 사이트를 검색하자!


## 코드 구현
---

```cpp
#include <iostream>
#include <map>

int main() {
    std::cin.tie(NULL);
    std::ios_base::sync_with_stdio(false);

    int N, M;
    std::cin >> N >> M;
    std::map<std::string, std::string> note;
    std::string outputs;

    for (int i = 0; i < N; i++) {
        std::string site;
        std::string pass;
        std::cin >> site >> pass;
        note.insert({site, pass});
    }

    for (int i = 0; i < M; i++) {
        std::string site;
        std::cin >> site;
        auto iter = note.find(site);
        outputs += iter->second + "\n";
    }
    std::cout << outputs;
    
    return 0;
}
```

## 분석
---
- **시간복잡도**
	- `map`에 삽입할 때: `O(logN)` -> N개를 삽입할 떄: `O(NlogN)`
	- 사이트를 검색할 떄: `O(logN)` -> M개를 검색할 떄: `O(MlogN)`
	- 총 시간복잡도: `O( (N+M)logN )` 
- **공간복잡도**
	- 사이트 N개, 비밀번호 N개를 저장: `O(N)` 
- **코드 구조**
	- 로그 시간복잡도, 선형 공간복잡도를 가지는 효율적인 알고리즘
	- 데이터 입력과 출력을 분리하여 구조를 파악하기 쉽다
